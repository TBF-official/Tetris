## 📥 Как скачать и запустить (в Termux)

Выполни следующие команды в своем терминале:

```bash
# 1. Клонируй репозиторий
git clone [https://github.com/TBF-official/Tetris.git](https://github.com/TBF-official/Tetris.git)

# 2. Перейди в папку с игрой
cd Tetris

# 3. Запусти игру
python tetris.py

🎮 Управление
 * Стрелка Влево / Вправо — двигать фигуру влево или вправо.
 * Стрелка Вниз — ускорить падение фигуры.
 * Пробел (Space) — повернуть фигуру.
 * Клавиша q — выйти из игры.
